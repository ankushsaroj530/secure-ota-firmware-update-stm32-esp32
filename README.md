# Secure Embedded Firmware Management & OTA Update System

## Phase 1 (Semester 7)

### Objective
Develop a custom STM32 bootloader capable of:
- UART-based firmware updates
- Flash programming
- CRC verification
- Firmware version management
- Recovery mode
- Jumping to the application safely

### Target Hardware
- STM32F103C8T6 (Blue Pill)
- ST-Link V2
- USB-to-UART Adapter
